# Almacen Mator

Real-world Warehouse Management System (WMS) designed to support daily warehouse operations, including inventory control, order preparation, task tracking, and virtual warehouse mapping.

Key Features
Multi-Warehouse Management
Manage multiple warehouses from a single platform.
Real-time stock visibility across all warehouses.
Inter-warehouse stock transfers.
Unified inventory control.
Inventory & Location Control
Real-time stock monitoring.
Product location tracking.
Complete inventory visibility.
Warehouse map visualization.
Space Optimization
Pallet capacity calculation by area.
Occupancy monitoring by sector.
Occupancy monitoring by warehouse.
Global occupancy analytics.
Available space tracking.
Mobile Operations
PDA support for warehouse operations.
Mobile-friendly workflows.
Fast product lookup and stock verification.
Operational Intelligence
Know exactly what material is stored in each sector.
Track available and occupied pallet positions.
Measure occupancy percentages by:
Sector
Warehouse
Entire operation

Warehouse Capacity Management
Almacén Mator not only manages inventory, but also warehouse capacity.

The system provides:

Pallet capacity per sector
Current pallet occupancy
Occupancy percentage by sector
Occupancy percentage by warehouse
Total occupancy percentage across all warehouses
Material visibility for every storage area
Available storage space calculation
This allows warehouse operators to make data-driven decisions about storage allocation and stock distribution.

Why This Project Is Different
Unlike most inventory applications, Almacén Mator was developed to solve real operational challenges in an active warehouse environment.

The platform combines inventory management, warehouse mapping, capacity planning, occupancy monitoring, and inter-warehouse logistics in a single system used daily by warehouse personnel.
